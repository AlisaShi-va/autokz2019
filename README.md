## Описание проекта
Датасет содержит данные по всем продажам автомобилей в Казахстане за девять месяцев 2019 года. Задача — подготовить данные и провести анализ, который поможет менеджменту «Меркур Авто» оценить свою эффективность и принять стратегические решения

#### Цели
- *Техническая цель*: довести датасет до состояния, пригодного для анализа. Создать скрипт его очистки для автоматизации обработки похожих данных в будущем.
- *Аналитическая цель*: провести разведочный анализ (EDA) всего рынка и дать оценку позиции и ключевым показателям эффективности автоцентра «Меркур Авто».

#### План работы
1. Загрузка и первичный осмотр данных
2. Глубокая очистка и преобразование данных
3. Исследовательский анализ данных (EDA)
4. Анализ рынка и позиции «Меркур Авто»
5. Подготовка итоговых артефактов: Отчет и Итоговый очищенный датасет
